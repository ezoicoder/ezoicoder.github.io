# 简历中英文翻译

适用于双语简历的翻译、对照和润色。

- 翻译自然、简洁的内容；如果直译生硬、含义不准确或不符合行业习惯，保留英文，必要时使用中英混合表达。
- 对技术术语、论文标题、机构名、会议名、系统名等，优先保留公认的英文名称，不要臆造中文译名。
- 保留事实、数字、日期、作者顺序、技术含义和表述强度，不因翻译夸大经历或成果。
- 中英文版本应保持含义和重点一致，但不强求句式逐字对应。
- 润色应服务于简洁、可信和易读；同时注意中英文版本的行宽和一页排版。

## 修改流程

先检查对应内容，给出具体翻译建议，并说明哪些内容建议翻译、保留英文或使用混合表达；只有用户明确同意后，才修改文件。用户只要求建议时，不编辑任何文件。
